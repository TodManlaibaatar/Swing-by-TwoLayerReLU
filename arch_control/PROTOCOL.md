# Matched-architecture control: protocol

Commit this file together with `experiments.py`, `simulate.py` and `metrics.py`
**before** running any protocol experiment. The runner refuses to start on a dirty
`arch_control/` tree and records the commit hash and the SHA-256 of these four
files in every manifest line.

## 1. Question

The predecessor (Yang et al., ICLR 2025) defines *Swing-by*: at the compositional
test point, the OOD error first falls, then transiently rises while the model
moves toward the strongest training concept, then falls again. Its theory uses
linear networks. On the canonical SIM dataset our two-layer ReLU network is
monotone at the compositional probe, while persistent reversals appear on
directions outside the positive concept cone.

This protocol separates two possible explanations.

* **(A)** ReLU removes compositional Swing-by and moves the non-monotonicity
  off-cone.
* **(B)** Compositional Swing-by is governed by width and initialization (it is
  absent in the wide, small, isotropic regime for *both* activations). The
  off-cone reversal is a separate phenomenon specific to ReLU.

**Design.** Every comparison is *paired*. Two runs with the same seed use
identical training data and an identical initialization `U(0) = W(0)`. They
differ only in the activation: ReLU versus identity. The parameterization is
`f(x) = sum_i w_i sigma(u_i^T x)` for both. The loss is
`L = (1/2N) sum_n ||f(x_n) - x_n||^2`. The dynamics are full-batch gradient
flow, integrated with forward Euler at `dt = 2e-4` in float64.

**Random-number convention.** Data and initialization are generated by the
repository's `make_data` and `init_model`. Each builds its own generator from
the same integer seed. So seed 0 reproduces the archived canonical run
bit-for-bit (validation V1). Positive-quadrant initializations use the same
convention.

## 2. Experiments (frozen in `experiments.py`)

| E1_canonical | headline matched control | (3, 2, 0.15) | ReLU, linear | 200 | iso, eps=1e-3 | 0-9 | 20 |
| E2_grid | preregistered nine-cell grid | (3, {1.8,2.0,2.2}, {0.12,0.15,0.18}) | ReLU, linear | 200 | iso, eps=1e-3 | 0-4 | 10 |
| E3_regime | width / init scale / init geometry | canonical; predecessor-like (1, 2, 0.05) | ReLU, linear | 2, 8, 32, 200 | iso, pos; s0 = h eps^2 in {2e-4, 2e-2} | 0-9 | 20 (canonical), 40 (predecessor) |
| E4_positive_control | detector sensitivity | (1, 2, 0.05) | tied `f = U^T U x` (predecessor model) | d' in {2, 4} | all entries positive, omega in {0.01, 0.05} | 0-9 | 60 |
| E5_stepsize | integrator refinement | (3, 2, 0.15) | ReLU, linear | 200 | iso | 0 | 10, dt in {2e-4, 1e-4} |

The initializations are:

* `iso`: angles uniform on the circle. This is the archived canonical scheme.
* `pos`: angles uniform in (0, pi/2). This supplies positive "minor" entries, as
  in the predecessor's Swing-by mechanism.
* `pos_entries`: each entry uniform on omega * [0.5, 1.5]. This is the
  predecessor's Fig. 5 setting.

At h = 200 and s0 = 2e-4, E3 uses eps = 1e-3 exactly, identical to E1.

## 3. Metrics (frozen in `metrics.py`)

**Directional error.** Let `xi_psi = (cos psi, sin psi)` be a unit probe. The
directional error is `E(psi, t) = 0.5 ||f_t(xi_psi) - xi_psi||^2`. It is logged
every 0.01 time units on the archived 720-direction grid (0.5 degree spacing)
and at eight named probes:

* the population compositional direction `(mu1, mu2)/||.||`;
* the empirical compositional direction;
* -85 degrees and 176 degrees;
* +-e1 and +-e2.

By positive homogeneity, the compositional probe equals the predecessor's
`E(x_hat)/||x_hat||^2`.

**Primary statistic: persistent increase `S(psi)`.** This is the archived
detector (`persistent_swing`): an 11-sample centred moving average, then the
largest increase from a local minimum that stays at >= 80% of its height for
0.20 time units. It is computed on the full window `[0, T]`. The archived phase
diagram used `[weak-branch birth, 10]`; V1 reproduces that separately.

**Secondary statistics.**

* `rise` = `max_t [E(t) - min_{s<=t} E(s)]` on the raw samples. This detects
  transient bumps.
* `final excess` = `E(T) - min_t E(t)`.

**Labels at threshold tau.**

* `monotone`: rise <= 1e-9.
* `transient` (Swing-by-like): rise >= tau and final excess <= 0.1 * rise.
* `persistent`: S >= tau and final excess > 0.1 * rise.

**Cone.** The closed positive cone is `cos psi >= -1e-12` and
`sin psi >= -1e-12`, the archived convention.

**Thresholds.** tau = 1e-4 is the archived reporting threshold. 5e-5 and 1e-5
are always reported alongside it.

## 4. Hypotheses and decision rules

* **H1** (wide regime, E1 and E2). In every run of both architectures, the
  compositional probes (population and empirical) are `monotone`. Supports (B);
  contradicts (A)'s premise.
* **H2a** (E1 and E2). No linear run has any direction with S >= 1e-5.
* **H2b** (E1 and E2). Every ReLU run has at least one off-cone direction with
  S >= 1e-4.
* **H2c** (reported, no prediction). ReLU in-cone counts at each threshold.
* **H3** (E1, T = 20). The ReLU -85 degree probe is `persistent` at 1e-4 in at
  least 9 of 10 seeds. Its reversal does not recover by T = 20.
* **H4** (E3, exploratory, no pass/fail).
  * Compositional rise as a function of width, init scale and init geometry,
    for each activation.
  * Paired ReLU/linear ratio of compositional rise, and its rank correlation.
  * Under (B) the paired rises are similar. Under (A) ReLU rises are
    systematically smaller where linear ones are large.
* **P1** (E4). In each of the four conditions, at least 90% of seeds are
  labelled `transient` at 1e-4 at the compositional probe. If P1 fails, the
  detector cannot certify the absence of Swing-by. H1 is then reported as
  inconclusive.

All runs and seeds are reported whatever the outcome. No run is excluded.

## 5. Validation

* **V1** (`validate.py`). The E1 ReLU seed-0 run reproduces the archived
  canonical trajectory: max |dU|, |dW| < 1e-9 for t <= 10. S recomputed on the
  archived 1022 directions over `[1.08, 10]` matches `phase_diagram.csv`: max
  |dS| < 1e-9, with 198/824 cone split, 230 above 1e-4 and 0 of them in-cone.
* **V2**. Linear networks are odd, so E(psi) = E(psi + 180 deg). The maximum
  asymmetry over all linear runs is reported.
* **V3**. The training loss is non-increasing at logged times in every run.
* **V4**. The vectorized detector equals the archived function (< 1e-12).
* **V5** (E5). Halving dt changes S by a reported amount and leaves the
  threshold counts unchanged.
